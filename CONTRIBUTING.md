# 🤝 Contribuire a CarMaintenance

Grazie per l'interesse a contribuire a **CarMaintenance**!

## 🛠️ Flusso di Sviluppo

1. **Crea un Branch Tematico**:
   ```bash
   git checkout -b feature/nome-funzionalita
   ```
2. **Installa le Dipendenze**:
   ```bash
   npm install
   ```
3. **Esegui i Test**:
   ```bash
   npm test
   ```
4. **Convenzioni di Commit**:
   Usa convenzioni semantiche come `feat:`, `fix:`, `docs:`, `test:`, `refactor:`.

5. **Apri una Pull Request**:
   Descrivi dettagliatamente le modifiche e collega le issue corrispondenti.
